# 事前登録：Gemini 3.8 Flash TTS の「大阪の声」は京阪式アクセントで話すか

版：v4（v1〜v3 を2回の外部レビューで改訂し、1本にまとめたもの）。
この文書を測定前に公開リポジトリ（ccie26302/zenn-code の `tts-dialect-accent/`）へ push し、タグ `tts-prereg-1` を打つ。
判定器の閾値は、陰性ゲートと合成対照の結果で決めてから `tts-prereg-2` で固定する。本測定はその後に流す。

## 0. 用語と主張の範囲

- 京阪式／東京式：語の高低（アクセント）の体系。今回の「京阪式」は大阪・京都の伝統的な体系を指す
- エセ関西弁：言葉づかいは関西弁なのに、名詞のアクセントが東京式のもの。嘲笑の意味では使わない
- 関西の母語話者による確認はしていない。正解は辞典（Wiktionary に出典つきで載る値）と類の対応で置く。したがって公開時点で言えるのは「伝統的な京阪式の対応に照らすと、選んだ大阪ラベル6声で、名詞の型の X% が東京式だった」まで。「関西の人が聞けばエセ」「Gemini は関西弁を話せない」とは書かない

## 3. 刺激

### 3.1 語（24語、正解は語ごと）

東京の型は Wiktionary の ja-pron（出典 NHK・大辞林・新明解ほか）。京阪の型は Wiktionary の Keihan 表記で確認できた語は「確認」、できない語は類の対応で置く（「類」）。

| 類 | 語 | 東京（名詞＋が） | 京阪（名詞＋が） | 京阪の根拠 |
|---|---|---|---|---|
| 1類 | 飴、鼻、水、鳥、庭、顔 | 低高高（平板） | 高高高 | 類 |
| 2類 | 紙、川、夢 | 低高低（尾高） | 高低低 | 確認 |
| 3類 | 山、耳、花 | 低高低（尾高） | 高低低 | 確認 |
| 4類 | 糸、海、針、稲、麦、肩 | 高低低（頭高） | 低低高 | 類 |
| 5類 | 雨、春、前 | 高低低（頭高） | 低高低 | 確認 |
| 5類 | 声、窓、鍋 | 高低低（頭高） | 低高低 | 類 |

- 同音の対：飴（1類）と雨（5類）、鼻（1類）と花（3類）。漢字で渡すので読みは字で決まる
- 読みが揺れる語・語頭が無声化しやすい語は除いた（音・空・牛・姉・風・北・橋・箸・松・夏・石）
- 5類は若い世代で4類型（低低高）に揺れるとの報告がある。5類の「低低高」は京阪式の揺れとして京阪式に数える
- 書き起こしで読みを確認し、別の語に読んだ発話は判定から外して別に数える

### 3.2 枠文とリクエスト

- 関西の枠：「〇〇があるねん。」／標準の枠：「〇〇があります。」
- 1リクエスト＝ダミー1文（先頭「机があるねん。」）＋24文＋ダミー1文（末尾「鞄があるねん。」）。標準の枠のダミーは「〜があります。」
- 文と文の間に `<long pause>` を入れる
- 24文の順番はリクエストごとに乱数（シード＝20260925＋リクエスト番号）。ただし同音の対（飴・雨、鼻・花）は隣り合わせない。文の位置を記録する

### 3.3 声（シード 20260925 で性別ごとに無作為抽出）

- 大阪ラベル6声：ja-jp-concierge-3（女30）、ja-jp-assistant-8（女24）、ja-jp-podcaster-3（女33）、ja-jp-advisor-6（男42）、ja-jp-storyteller-9（男38）、ja-jp-storyteller-2（男27）
- 東京ラベル3声：ja-jp-csagent-11（女32）、ja-jp-tutor-10（女55）、ja-jp-podcaster-1（男57）
- 母集団は「選んだこの6声・3声」。大阪ラベル22声全体への一般化はしない

### 3.4 指示（`speech_metadata.style`）

- K：「大阪出身の人として、自然な関西のアクセントで」
- T：「東京出身の人として、標準語のアクセントで」
- N：注記なし（指示なし）

## 5. 測り方

### 5.1 切り分けと拍の区間

1. Speech-to-Text v2（Chirp 3、us）で書き起こし、語の時刻を得る。各文を「名詞」の開始から「ねん／ます」の終わりまで切り出す
2. torchaudio の MMS 強制アライメント（ローマ字の文字単位）で拍の区間を得る。拍の区間＝その拍の最初の文字の開始から次の拍の最初の文字の開始まで
3. F0：parselmouth の自己相関法、5ms ごと。声・リクエストごとに探索範囲を2段階で決める（15%点×0.75〜85%点×1.5）。最大強度から25dB以上弱いフレームを除く。中央値から1.8倍以上・0.55倍以下のフレームは半分・倍に直す
4. 各拍（名詞の2拍と「が」）の区間の中央50%の有声フレームの平均を半音（100Hz 基準）にする。有声フレームが3つ未満の拍があれば「判定不能（無声）」

### 5.2 型の判定

d1＝2拍目−1拍目、d2＝「が」−2拍目（半音）。θ を閾値として、各差を ＋（θ超）／0／−（−θ未満）に分ける。

| 類 | 東京式と判定 | 京阪式と判定 |
|---|---|---|
| 2・3類 | d1＝＋ かつ d2＝− | d1＝− |
| 4類 | d1＝− | d1≠− かつ（d2＝＋ または d1＝＋） |
| 5類 | d1＝− | d1＝＋（d2 は問わない）、または d1＝0 かつ d2＝＋（4類型への揺れ） |
| 1類（副） | d1＝＋ | 3拍の幅が θ 未満（平ら）→「京阪候補」として別枠 |

- どちらにも当たらないものは「どちらでもない」
- 3拍の幅（最大−最小）が θ 未満の発話は、1類以外では「平ら・判定不能」
- 主解析は 2・3・4・5類の18語。1類は平らな読みが京阪式と区別できないため副次として別に報告する
- θ の既定は 1.5半音。段階5.3の結果で見直し、`tts-prereg-2` で固定する

### 5.3 判定器の検証（本測定の前）

- 陰性ゲート：東京3声×N×標準の枠（段階1）。2・3・4・5類で東京式と判定される割合が80%以上なら合格。80%未満なら本測定の結論を出さない（判定器か前提の見直し）
- 合成対照（API 不要）：陰性ゲートの音声を parselmouth の PSOLA で加工し、名詞＋「が」の高さを京阪式の型に書き換える。振れ幅は 1・2・4・6半音、拍境界に±20ms の揺らぎ、低起の上昇はなだらかにする。類ごと・振れ幅ごとに、京阪式と判定される割合（検出率）の曲線を出す
- θ は、振れ幅2半音の合成対照で類ごとの検出率が85%以上になり、かつ陰性ゲートで東京式80%以上を保つ最大値にする。満たす θ がなければ「判定器は○半音未満の対比を検出できない」と記事に書き、θ は既定のままにする
- 合成対照は標準の枠から作るので、関西の枠の文とは文が違う（弱点として記載）

## 6. 分析と事前予測

- 主要な評価項目は2つ：(1) 大阪6声×K×関西の枠での京阪式一致率、(2) 同じ条件での東京式一致率（エセ率）。分母は判定できた件数。判定不能・どちらでもないは別に報告
- 主な図：6声それぞれの京阪式一致率を点で並べる
- 区間：6声それぞれについて語（18）で区切ったブートストラップ（10,000回）、全体は声×語の2段ブートストラップ（声が6なので区間は参考）
- 事前予測
  - P1（判定器）：5.3 の合格基準を満たす。満たさなければ以降は判定しない
  - P2：大阪6声×K×関西の枠の京阪式一致率は、6声中5声以上で70%未満
  - P3：同じ条件のエセ率（東京式一致率）は、全体で20%以上（2段ブートストラップの95%区間の下限で判定）
  - P4：再現性：同じリクエスト2回で、型の判定が食い違う発話の割合（記述、95%区間つき）
  - P5（探索的）：大阪6声×K の京阪式一致率は、東京3声×K より高い
  - P6：大阪6声に T（東京の指示）を与えると、東京式一致率は K のときより20pt以上高くなる（指示が効く）
  - P6'：大阪6声の N と K の差は10pt未満（関西の指示は大阪の声の既定からほとんど変えない）
  - P7（参考）：3.1（Vertex AI）の値は比較せず記述のみ

## 7. Q2 お嬢様と関西弁（長文の一発どり）

- 文章（オリジナル、10文。どれも「〜わ」で終わり、お嬢様にも関西弁にも読める）：
  いえ、そんな話は知りませんわ。昨日のことでしたら、もう忘れましたわ。あのお店、今日はお休みですわ。雨が降ったら困りますわ。明日は早めに参りますわ。お茶でしたら、もう頂きましたわ。その件はお断りしますわ。本当に、びっくりしましたわ。今日はもう無理ですわ。それでは、また来ますわ。
- 指示：お嬢様「上品なお嬢様として、おっとりと」／関西「大阪出身の女性として、自然な関西弁で」／N
- 声：大阪女性1（concierge-3）、東京女性1（csagent-11）。各2テイク
- 測り方：各文の最後の「わ」の拍と直前の拍の高さの差（半音）と、「わ」の長さ
- P8（主）：文10件を単位に、声とテイクで平均した「わ」の高さの差は、お嬢様と関西で異なる（符号付き順位検定、両側 p<0.05）。方向は予測しない
- 聴き取り：ユーザー（関西の母語話者ではない）が、条件を伏せ順番を無作為にした20件（お嬢様10・関西10の文単位の切り出し）を2択で判定。15件以上正解で「区別できる」（片側 p≈0.02）。示せるのは「区別できる」ことまでで、「本物らしい」ことではない
- 元ネタの「叙述トリックお嬢様」の文章は使わない（創作物のため）。記事ではリンクで紹介する

## 8. Q3 文字の書き換え（追加の呼び出しなし）

- 段階1・2の全音声を Chirp 3 で書き起こし、名詞の置き換え（飴→飴ちゃん等）、枠の語の置き換え（あるねん→ありますねん等）を拾う。「あるねん→あんねん」の縮約は別カテゴリ
- 同音語（飴・雨、鼻・花）は書き起こしでは区別できないので、検出できるのは語の追加・置換だけと明記
- 拾った件は全件を人（筆者）が聴いて確認。拾わなかった件から10%を抜き取って確認

## 11. 分かっている弱点

- 主解析18語のうち9語（4類6語、5類の声・窓・鍋）と、副次の1類6語は、京阪式の正解を類の対応に頼る
- 関西の母語話者の音声で判定器を確かめていない（合成対照のみ）
- 声のラベル「Osaka Japanese」の意味（学習データの話者の出身か）は非公開。24歳の声もあり、現実の若い大阪話者の東京化と区別できない
- 1リクエストに26文を続けて読ませるため、文をまたいだ抑揚の影響がありうる（位置を共変量として記録）
- 3.8 本体は Gemini API で、Vertex AI にはまだ無い
