# Qwen Code は Claude Code の代わりになるか

Zenn の記事「Qwen CodeはClaude Codeの代わりになるか」の検証の手順とデータです。

- `PLAN.md` 計画(予備試行の前にコミットした事前登録)と変更履歴
- `REPRODUCE.md` 再現手順
- `tasks/` 43課題(依頼文・初期状態・判定・模範解答・惜しい誤答・別解)と判定の確認結果(`validation.csv`、`gvalidation_v2.csv`)
- `harness/` 隔離のコンテナ、中継(モデル・Google Cloud への出口)、試行と片付けのスクリプト、カスタムロールの定義、負の対照の結果
- `reader/` 記事で紹介した、Agent Platform につなぐための手元の中継と設定の例
- `runs/{C,Q,L}/` 本測定の全387試行の記録(row.json、judge.json、エージェントの出力、中継の記録)。`PILOT*` は予備試行
- `reports/main/` 集計(summary.md、per_task.csv、rows.csv)と判定の確認(review.md)
- `notes/` 測定の外で確かめたこと(外への通信、文脈長、料金)
- `sources/` 課題の元にした、Claude Code で端末の作業をした公開記事の一覧

プロジェクト ID・アカウント・プロジェクト番号は `<target-project>` などに置き換えています。
