# L の試行中の消費電力(2026-10-21、M4 Max 128GB、140W アダプタで充電中)

ioreg の AppleSmartBattery の PowerTelemetryData.SystemPowerIn(システム全体の入力電力、mW)を2秒ごとに記録した(measure.sh)。画面などを含むシステム全体の値。

| | 時間 | 平均 | 中央値 | 最大 | 電力量 |
|---|---|---|---|---|---|
| 待機(60秒) | - | - | 4.5W | - | - |
| L M2_01(合格) | 279秒 | 106W | 124W | 129W | 8.19Wh |
| L R_B2_01(合格) | 247秒 | 65W | 78W | 115W | 4.48Wh |

本測定の L の合計 29.7時間に、平均 65〜106W をかけると約 1.9〜3.1kWh。2課題だけの値なので目安。
