# owata2-system1-realtime

Zenn 記事「人生オワタ2を600回、Jev互換AIは穴を越えられず」の測定コードと生データです。手順は [REPRODUCE.md](REPRODUCE.md)、記事の表は `python3 report.py` で出し直せます(出力例は [data/REPORT.md](data/REPORT.md))。

- ゲームは作者キング氏の公式ページ(Ruffle で再公開)をそのまま開いて遊びます。SWF、ゲーム画面、録画、画面から切り出したお手本は含めていません
- 自動操作では広告・計測のリクエストを遮断し、ページの読み込みを最小限にしています
- 目のお手本は REPRODUCE.md の手順で、自分で撮った画面から作ります
