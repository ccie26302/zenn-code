# 操作の説明書(実測, 2026-10-02, 1面スタート地点)
- ←→: 移動(地上で約2.6〜2.8px/コマ)。**空中でも左右に動ける**(右を20コマ押すと+52px、40コマで+112px)。
- Z: ジャンプ。**押すコマ数で高さが変わる**: 1→24px / 2→34 / 4→53 / 8→106 / 12→129 / 16以上→131px(上限)。滞空 19〜52コマ。
- X: オワタバスター(右手を伸ばして「○」の弾を前に撃つ)。
- S: **ポーズ**(自機が「<(^o^)／ ／<」の決めポーズ)。ゲームは止まらない(一時停止ではない)。
- ↑↓・P・Space・Enter: 押している最中の画像で目に見える変化は確認できず。
- R: リトライ / ESC: 自爆。
